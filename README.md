# 🌍 Child Labour Analysis (2020–2024) | SQL & Power BI

## Project Overview
This project analyzes child labour data from 2020–2024 using SQL and Power BI to uncover trends across countries, regions, gender, and age groups. The findings translate raw data into actionable insights that support evidence-based decisions for monitoring child labour and prioritizing intervention efforts.

## 🎯 Business Problem
Child labour remains a significant challenge, with varying prevalence across countries, regions, gender, and age groups. This project analyzes data from 2020–2024 to identify the most affected populations and support data-driven intervention and policy decisions.

## ❓Business Questions
- What is the average child labour percentage?
- Which countries or regions have the highest child labour rates?
- Which countries report the lowest child labour rates?
- How has child labour changed over time?
- Is child labour more prevalent among males or females?
- Which age group is most affected?
- Which ten countries report the highest child labour rates?
- How do child labour trends compare by gender over time?

### 📂 Dataset
- Source: UNICEF Child Labour Dataset Years 
- Covered: 2020–2024 

## 🛠️ Tools Used
- SQL
- Power BI
- Microsoft Excel

## 💡Key Insights
- Average child labour rate: 12.20%
- Burundi recorded the highest child labour rate.
- Russian Federation recorded the lowest reported rate (0%).
- Child labour declined from 2020–2023, with a slight increase in 2024.
- Children aged 5–17 were the most affected.
- Males consistently recorded slightly higher child labour rates than females.


## 📈Recommendations
- Prioritize interventions in high-risk countries and regions.
- Strengthen education and child protection programmes for vulnerable age groups.
- Monitor yearly trends to support timely policy decisions.
- Improve data collection to enable more effective evidence-based planning
